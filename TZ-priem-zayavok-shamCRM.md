# ТЗ: приём анкет со страницы партнёров в shamCRM

**Для:** техотдела shamCRM
**Страница:** https://irodaxoncrm.github.io/shamcrm-partners/ (позже, возможно, свой домен, например partners.shamcrm.com)

## Задача

Страница партнёров отправляет в shamCRM два вида данных:

1. **Анкету партнёра.** Из неё нужно создать лид.
2. **Результат экзамена.** Его нужно добавить к тому же лиду.

Отдел партнёров должен видеть всё это в shamCRM, без ручного переноса из Telegram и почты.

Со стороны страницы всё готово. Нужен только адрес в shamCRM, который принимает эти запросы.

## Что нужно сделать

### 1. Адрес для приёма заявок

- Метод `POST`, протокол HTTPS, тело в формате JSON (`Content-Type: application/json`).
- Ответ при успехе: код `200` и JSON вида:
  ```json
  { "ok": true, "lead_id": "12345" }
  ```
  `lead_id` — номер созданного или обновлённого лида. Страница запомнит его и пришлёт вместе с результатом экзамена.
- Ответ при ошибке: любой код, кроме 2xx, или `{ "ok": false }`. Тогда страница предложит партнёру отправить анкету в Telegram или на почту.

### 2. Без секретного ключа

Код страницы открытый: на GitHub его может посмотреть любой. Поэтому **секретный ключ API на странице размещать нельзя.**

Есть два варианта:
- адрес вообще без ключа;
- **публичный ключ формы** (`form_key`), который умеет только создавать и обновлять лиды из этой формы. Читать, удалять и менять другие данные с ним должно быть невозможно.

### 3. CORS

Страница открывается с другого домена, поэтому браузер сначала отправляет запрос `OPTIONS`. На него нужно отвечать кодом `204` с такими заголовками:

```
Access-Control-Allow-Origin: https://irodaxoncrm.github.io
Access-Control-Allow-Methods: POST, OPTIONS
Access-Control-Allow-Headers: Content-Type
```

Если подключим свой домен, в разрешённые нужно будет добавить и его.

### 4. Защита от спама

- Не больше 20 запросов в час с одного IP.
- Размер тела запроса — до 100 КБ.
- Проверять, что `type` равен `anketa` или `exam` и что есть хотя бы телефон, почта или ФИО.

## Запрос 1: анкета (`type: "anketa"`)

| Поле | Что это | Куда в shamCRM |
|---|---|---|
| `type` | Всегда `"anketa"` | — |
| `lead_id` | Номер лида, если анкету отправляют повторно (исправили ответы). Иначе `null` | Обновить этот лид, а не создавать новый |
| `client_id` | Постоянный номер устройства партнёра | Сохранить в лиде, чтобы найти его при получении экзамена |
| `company` | Название для лида: рекламное, а если его нет — юридическое | Название лида / компания |
| `legal_name` | Юридическое наименование | Реквизиты компании |
| `brand` | Рекламное наименование | Компания |
| `inn` | ИНН | Реквизиты |
| `site` | Сайт | Компания |
| `ceo` | ФИО руководителя | Компания / комментарий |
| `contact_name` | ФИО контактного лица | Контакт |
| `position` | Должность контактного лица | Контакт |
| `phone` | Телефон | Контакт |
| `email` | Почта | Контакт |
| `potential_clients` | Сколько клиентов уже готовы работать с партнёром | Поле лида |
| `team_size` | Сколько сотрудников планируют задействовать | Поле лида |
| `source` | Откуда узнали о программе | Поле лида |
| `answers` | Все ответы анкеты: `[{section, question, answer}]` | Комментарий или описание лида |
| `text` | Вся анкета одним текстом | Комментарий лида (если `answers` неудобно) |
| `submitted_at` | Дата и время отправки (ISO 8601, UTC) | Дата |
| `page_url` | Адрес страницы | Источник |
| `form_key` | Публичный ключ формы, если он есть | Проверка |

**Что сделать в CRM:**
- Если пришёл `lead_id` и такой лид существует, обновить его.
- Иначе создать новый лид в воронке **«Партнёры»** на этапе **«Анкета получена»**, с источником **«Страница партнёров»**.
- Назначить ответственного из отдела партнёров и отправить ему уведомление.

## Запрос 2: результат экзамена (`type: "exam"`)

| Поле | Что это |
|---|---|
| `type` | Всегда `"exam"` |
| `lead_id` | Номер лида из ответа на анкету. `null`, если анкету заполняли на другом устройстве |
| `client_id` | Номер устройства (тот же, что в анкете, если устройство одно) |
| `name` | ФИО для сертификата |
| `company` | Компания |
| `phone`, `email` | Из анкеты, если её заполняли на этом устройстве |
| `mode` | `partner_40` — экзамен партнёра, 40 вопросов; `full_240` — полный тест, 240 вопросов |
| `correct`, `total`, `percent` | Правильных ответов, всего вопросов, процент |
| `passed` | `true` — сдан (не меньше 80% по каждому модулю), `false` — не сдан |
| `modules` | Результат по модулям: `[{module, title, correct, total}]` |
| `finished_at` | Дата и время окончания экзамена |

**Что сделать в CRM:**
- Найти лид по порядку: `lead_id` → `client_id` → телефон или почта → ФИО и компания.
- Добавить в лид комментарий с результатом, например: «Экзамен партнёра: 36/40 (90%), сдан. Модули: 9/10, 9/10, 10/10, 8/10».
- Если `passed: true`, перевести лид на этап **«Экзамен сдан»**.
- Если лид не нашёлся, создать новый с пометкой «экзамен без анкеты».

## Предлагаемые этапы воронки «Партнёры»

Анкета получена → Договор отправлен → Договор подписан → Обучение → Экзамен сдан → Сертификат выдан, работает

## Как проверить

```bash
curl -i -X POST 'https://АДРЕС/' \
  -H 'Content-Type: application/json' \
  -H 'Origin: https://irodaxoncrm.github.io' \
  -d '{"type":"anketa","company":"Проверка","contact_name":"Тест","phone":"+998900000000","email":"test@example.com","text":"тест"}'
```

Ожидаемый ответ: `200`, `{"ok":true,"lead_id":"…"}`, а в shamCRM появился лид «Проверка».

## Что передать отделу партнёров после готовности

1. Адрес приёма заявок.
2. Публичный ключ формы, если он есть.

Оба значения вписываются в файл `config.js` в репозитории страницы. Больше ничего менять не нужно.
