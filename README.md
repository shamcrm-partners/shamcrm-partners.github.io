# Партнёрская программа shamCRM

**Сайт:** https://shamcrm-partners.github.io/

Информационная страница для партнёров shamCRM в пять шагов: анкета → договор → обучение → экзамен → сертификат.

- **Анкета и договор** — рабочие. Партнёр заполняет анкету. Договор открывается прямо на сайте, уже заполненный данными из анкеты, и скачивается в PDF одной кнопкой.
- **Обучение, экзамен и сертификат** — только информация: план обучения на 4 дня, формат экзамена, условия получения сертификата и его образец. Сам экзамен проводит отдел партнёров по файлам, сертификат выдаёт отдел.
- Два языка, переключатель UZ / RU вверху. По умолчанию узбекский.

Это обычный статический сайт. Он работает на GitHub Pages бесплатно, без сервера и без подписок.

## Договор

После анкеты на шаге «Договор» открывается договор с данными партнёра: организация, руководитель, ИНН, адрес, город, банк, расчётный счёт, МФО, телефон, почта. Пустые поля остаются линиями. Договор показан листами A4, как в PDF.

Кнопка **«Скачать договор (PDF)»** сразу скачивает файл `Dogovor-shamCRM-<название>.pdf` с этими данными. PDF собирается в браузере за несколько секунд, сервер не нужен.

Текст договора — на русском языке. Пока анкета не заполнена, договора на сайте нет: вместо него кнопка «Сначала заполнить анкету».

## Анкеты в Google Таблицу

1. Откройте таблицу «Анкеты партнёров shamCRM» → **Расширения → Apps Script**.
2. Вставьте туда весь код из `google-sheets/Code.gs` и сохраните.
3. **Начать развёртывание → Новое развёртывание → Веб-приложение**: «Запуск от имени» — Я, «У кого есть доступ» — Все → **Развернуть** → разрешите доступ.
4. Скопируйте адрес веб-приложения (заканчивается на `/exec`) и вставьте его в `config.js` в поле `sheetUrl`.

Каждая анкета появится в таблице новой строкой. Колонки «Статус» и «Комментарий менеджера» — для отдела партнёров.

## Как подключить shamCRM

1. Техотдел делает приём заявок и выдаёт адрес.
2. На GitHub откройте `config.js`, нажмите на карандаш (Edit) и вставьте адрес в `crmUrl`:
   ```js
   crmUrl: 'https://адрес-от-техотдела',
   ```
3. Нажмите **Commit changes**. Через 1–2 минуты страница обновится сама.

Пока `sheetUrl` и `crmUrl` пустые, партнёр отправляет анкету сам: в Telegram (@shamcrm_uz), на почту или копирует текст.

## Что попадает в таблицу или CRM

Компания, ИНН, сайт, город, банковские реквизиты, руководитель, контакт, телефон, почта, число потенциальных клиентов и все ответы анкеты (на русском, даже если партнёр заполнял по-узбекски; язык анкеты — в поле `lang`).

## Сертификаты

Сертификаты партнёрам выдаёт отдел партнёров: генератор сертификатов или шаблон PowerPoint.
