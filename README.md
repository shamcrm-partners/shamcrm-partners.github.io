# Партнёрская программа shamCRM

**Сайт:** https://shamcrm-partners.github.io/

Страница для партнёров shamCRM в пять шагов: анкета → договор → обучение → экзамен → сертификат.

Это обычный статический сайт. Он работает на GitHub Pages бесплатно, без сервера и без подписок.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Сама страница |
| `config.js` | **Куда отправлять анкеты: Google Таблица и/или shamCRM.** Это единственный файл, который нужно менять |
| `exam.json` | Вопросы экзамена (240 вопросов, 4 модуля) |
| `cert-template.jpg` | Шаблон сертификата: ФИО и дата подставляются автоматически |
| `promo.mp4`, `promo-poster.jpg` | Ролик для продаж и его обложка |
| `logo-white.png`, `mark-white.png` | Логотипы |
| `vendor/jspdf.umd.min.js` | Библиотека для скачивания сертификата в PDF |
| `files/Dogovor-shamCRM.pdf`, `files/Dogovor-shamCRM.docx` | Партнёрский договор: PDF для чтения и пустой бланк |
| `files/Dogovor-shamCRM-shablon.docx` | Шаблон договора с метками `{{legal_name}}`, `{{inn}}` и т.д. — сайт подставляет в него данные анкеты. Если меняете текст договора, обновите и шаблон (метки должны остаться) |
| `google-sheets/Code.gs` | Код для Google Таблицы, которая принимает анкеты |
| `TZ-priem-zayavok-shamCRM.md` | ТЗ для техотдела: как shamCRM должна принимать анкеты |

## Анкеты в Google Таблицу

1. Откройте таблицу «Анкеты партнёров shamCRM» → **Расширения → Apps Script**.
2. Вставьте туда весь код из `google-sheets/Code.gs` и сохраните.
3. **Начать развёртывание → Новое развёртывание → Веб-приложение**: «Запуск от имени» — Я, «У кого есть доступ» — Все → **Развернуть** → разрешите доступ.
4. Скопируйте адрес веб-приложения (заканчивается на `/exec`) и вставьте его в `config.js` в поле `sheetUrl`.

Каждая анкета появится в таблице новой строкой, результат экзамена допишется в ту же строку. Колонки «Статус» и «Комментарий менеджера» — для отдела партнёров.

## Как подключить shamCRM

1. Техотдел делает приём заявок по ТЗ из файла `TZ-priem-zayavok-shamCRM.md` и выдаёт адрес.
2. На GitHub откройте `config.js`, нажмите на карандаш (Edit) и вставьте адрес в `crmUrl`:
   ```js
   crmUrl: 'https://адрес-от-техотдела',
   ```
3. Нажмите **Commit changes**. Через 1–2 минуты страница обновится сама.

Пока `crmUrl` пустой, страница работает как раньше: партнёр отправляет анкету в Telegram или на почту.

## Что попадает в CRM

- **Анкета.** Компания, ИНН, контакт, телефон, почта, число потенциальных клиентов и все ответы анкеты.
- **Результат экзамена.** ФИО, компания, баллы по каждому модулю, сдан или нет. Результат привязывается к тому же лиду.

## Обучение и экзамен

- **Обучение** — 4 модуля, у каждого список тем. Темы составлены по вопросам экзамена.
- **Видеоуроки.** В `index.html` найдите `var MODS=[` и в нужном модуле вставьте ссылку в `video: ''`. Подходит ссылка на YouTube или файл, загруженный в репозиторий (например `video/modul-1.mp4`). Пока ссылки нет, у модуля написано «Видеоурок появится позже».
- **Экзамен** — 40 случайных вопросов из всех 240 в `exam.json`, проходной балл 80% (32 из 40). Количество и балл — `EXAM_SIZE` и `PASS` в `index.html`.

## Для отдела партнёров

По адресу страницы с `#otdel` в конце (`https://shamcrm-partners.github.io/#otdel`) можно выдать сертификат вручную, если экзамен принимали устно. В меню этой ссылки нет.
